# 项目文档中心

更新日期：2026-11-13（北京时间）。

长期目标是让普通人用日常语言完成设计、加工准备、组装和打样修正。产品形态为操作专业 CAD 的桌面 Harness，支持完整工作台与悬浮小窗。现有网页与 CadQuery 保留为原型；首个验证对象已选定 FreeCAD 1.1.4，[原生工程脚本验证](../research/freecad-native/README.md)已通过，下一步接入 Harness 持续会话。

## 阅读顺序

1. [产品目标](product.md)：用户是谁、要解决什么问题、怎样判断产品有用。
2. [桌面 Harness 与悬浮小窗](desktop-harness.md)：窗口形态、上下文同步、焦点与人机协作规格。
3. [实施路线](roadmap.md)：CAD 接入、桌面形态、可靠操作和实物验收阶段。
4. [使用指南](usage.md)：现有原型的安装、启动、模型接入与数据备份。
5. [技术说明](architecture.md)：现有代码、请求流程、参数、模块和维护方式。
6. [验证记录](validation.md)：已有测试的范围、证据位置和未验证事项。

## 如何更新

需求和方向调整先改产品目标与路线；功能落地后同步使用及技术说明；验证完成后再更新能力状态和证据。记录失败案例与未覆盖事项，不把模型的文字承诺当成检查结果。

纯文档整理检查链接、命令、路径和事实，不重新生成模型或发起付费请求。涉及程序行为的变更运行相应测试。提交和发布步骤见[技术说明](architecture.md)。
