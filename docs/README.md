# 项目文档中心

更新日期：2026-11-13（北京时间）。

长期目标是让普通人用日常语言完成设计、加工准备、组装和打样修正。当前已有 Electron 桌面 Harness 开发版和 FreeCAD 1.1.4 常驻宏桥接；完整工作台和悬浮小窗共享同一会话。原有网页与 CadQuery 保留为原型。具体支持范围、实测和待验收项以[验证记录](validation.md)为准。

## 阅读顺序

1. [产品目标](product.md)：用户是谁、要解决什么问题、怎样判断产品有用。

3. [实施路线](roadmap.md)：CAD 接入、桌面形态、可靠操作和实物验收阶段。
4. [使用指南](usage.md)：桌面应用及保留原型的安装、启动、模型接入与数据备份。
5. [技术说明](architecture.md)：桌面分层、请求流程与执行边界；[开发指南](development.md)说明改哪里、如何测试和提交。
6. [验证记录](validation.md)：已有测试的范围、证据位置和未验证事项。
7. [原生设计指南](native-designs.md)：复杂多零件、尺寸编辑、连续修改和原生能力边界。
8. [Agent 技能、工具与视觉检查](agent-tools.md)：流式交互、技能导入、工具开关及 CAD 截图。

10. [连接与单窗口使用](cad-connection.md)：自动配置组件、原窗口升级、工程续改和测试约定。
11. [保留的网页原型](prototype.md)：原来的 CadQuery 方案、组件预览、参数与版本数据。
12. [变更记录](changelog.md)：版本变更与验证索引。
13. [交付与使用体验](release-readiness.md)：下一阶段的 Windows 内测版、安装/首次使用、项目续接、稳定性及放行条件（规划）。

## 如何更新

需求和方向调整先改产品目标与路线；功能落地后同步使用及技术说明；验证完成后再更新能力状态和证据。记录失败案例与未覆盖事项，不把模型的文字承诺当成检查结果。

纯文档整理检查链接、命令、路径和事实，不重新生成模型或发起付费请求。涉及程序行为的变更运行相应测试。提交和发布步骤见[开发指南](development.md)。
