# 能力状态与验证记录

截至2026-11-13（北京时间）。本页集中记录已经完成的验证，不把规划当成现有功能。产品验收目标见[实施路线](roadmap.md)。

## 应用自动测试

仓库根目录运行 `npm test`。当前共21个测试通过：桌面15项、网页原型6项。桌面覆盖精确指令、尺寸算式拒绝代码/无效值、结构数量与ID校验、参数保留和影响范围、旧协议及手改拒绝、并发请求、暂停/重复确认、过期计划、重启恢复和迟到结果；新增独立Node运行时选择、Electron环境变量清理和简洁错误提示，示例创建允许空/重复默认尺寸。源码见 [`session.test.mjs`](../desktop/test/session.test.mjs)、[`design.test.mjs`](../desktop/test/design.test.mjs)与[`node-runtime.test.mjs`](../desktop/test/node-runtime.test.mjs)。原型测试覆盖：

- 四孔安装板的尺寸、解析体积、孔径/孔心、STEP/STL输出与参数修改。
- 几何失败、非法导入与不合法参数的拒绝，失败不追加有效版本。
- 预览不修改原版本、取消恢复、保存与预览一致、重复保存不新增版本。
- 中文命名的三个模块、独立实体与体积；只移动滑台时其他模块不变；空模块拒绝。
- 参数单位/范围/整数规则，以及建模工具Schema与Agent工具限制。
- 独立组件网格的三角面边界与测量一致；旧版本显示缓存重建不改项目记录，并发复用缓存；预览保存保留组件文件。
- 分离位移可归零，对模型整体平移不敏感，不修改原始边界，重心重合时也能生成不同且有限的显示位移。

测试使用独立临时数据目录，不通过真实大模型生成。源码见 [`cad-studio/test/`](../cad-studio/test/)。

## 桌面与 FreeCAD 常驻桥接实测

2026-11-13，Windows、Electron45.3.1、FreeCAD1.1.4。独立常驻 GUI 桥接通过9组集成检查：连接、创建原生四孔板并读取选择、修改四孔直径、在真实写入边界拒绝过期计划、撤销、重做、保存到新路径、拒绝覆盖、拒绝不支持操作及非法孔径。记录见 [`native-results.json`](../desktop/validation/native-results.json)；最终为80×40×5mm、四孔8mm、单个有效实体，体积14994.690350851264mm³。该运行没有重新验证文件重开，重开证据仍来自原探针。

复现：设置 `FREECAD_EXE` 后运行 `node desktop/test/native-check.mjs`，会打开专用测试实例，工程留在 `desktop/.data/validation/`。运行结果只导出经过选择的测量摘要，不发布私有会话或工程。

另用已有 DSH 的 `deepseek-account` / `deepseek-flash` 实际完成用途问答；把“请把现在选中的四孔特征的直径增加到8毫米，板厚和位置别动”转为待确认计划，再通过同一 Session 确认执行，读回 `[8,8,8,8]`。摘要见 [`harness-results.json`](../desktop/validation/harness-results.json)。这证明有限工具可由模型规划，不代表任意自然语言和任意造型都已支持。

首轮窗口观察确认完整布局与紧凑布局均显示，输入“做一个四孔安装板”后缩小仍保留草稿，在小窗发送后显示待确认计划。后续自动化点击遇到窗口遮挡，未继续把它计为成功；尚未完成手动选择、拖动调整、置顶、快捷键、执行中切换、多屏、取消模型思考、退出保留CAD等系统交互验收。后端单次确认、暂停和重启不重放由自动测试覆盖，不替代这些手动验收。

附件只保存副本并展示文件名，模型未理解内容；单会话、有限CAD白名单、无安装器。复杂工程指纹性能、迟到结果、断连和崩溃恢复仍需专项验证；当前不可将开发版称为通用 CAD 自动化或制造交付系统。

## 原生复杂模型与连续修改实测

### Electron模型启动回归（2026-11-13）

用户实际输入“我想做一个飞机模型”触发 `Unsupported/no-context`。已复现：Electron45.3.1内置Node24.22.2以 `ELECTRON_RUN_AS_NODE` 启动DSH时，原生require-builtin模块不可用。此前4轮复杂模型测试从独立Node启动，没有覆盖这条桌面路径，不能作为该路径已通过的证明。

修复为桌面启动器传递独立Node路径，Harness启动前探测并使用它，拒绝Electron运行时并清除run-as-node变量。首次复测还发现模型返回 `example:airplane, changes:{}` 被误拒绝，已修复为新建示例采用默认值；更新已有模型仍拒绝无变化参数。

新增[`Electron回归记录`](../desktop/validation/electron-runtime-results.json)：真实Electron主进程中调用同一个Session/Harness，DSH实际子进程为独立Node24.22.3；两轮真实请求“我想做一个飞机模型”“机翼展长改成120毫米，其他不变”均规划、确认并执行成功。生成三个有效Body，修改翼展保留机身与尾翼，保存原生飞机工程。回归使用隔离工作区，不覆盖用户数据，不等同于完成UI点击验收。

显式复现命令：设置已有DSH登录配置与 `FREECAD_EXE` 后运行 `node desktop/test/run-electron-harness.mjs`。它会打开测试CAD并请求模型，不随普通 `npm test` 自动执行。桌面运行时错误的技术摘要脱敏保存在私有 `model-errors.log`，对话不再倾倒原生诊断栈。

新增能力与复现步骤见[原生设计指南](native-designs.md)。当前成功证据：

- [`complex-results.json`](../desktop/validation/complex-results.json)：控制盒2个Body、龙门架5个Body、飞机3个Body，共20组检查。包括创建、参数修改与无关零件测量保留、撤销/重做、组件选择和保存；滑台移动验证世界坐标；滑台过窄导致双实体时，整次事务中止并保留原模型。
- [`reopen-results.json`](../desktop/validation/reopen-results.json)：3种模型加交叉孔试块的20项重开检查，以及3项XYZ草图方向的实际材料点检查，再增加4项相同几何但插入用户特征的保护检查，共27项，保存、关闭、重开后配方与稳定签名一致，可继续修改和撤销；直接改原生特征后拒绝用旧配方覆盖。首轮发现BRep序列化导致误判，改为稳定原生数据和测量签名后复验通过。
- [`model-complex-results.json`](../desktop/validation/model-complex-results.json)：4轮真实DSH规划并确认执行：100×70×35mm控制盒；只将盖厚3→4；选择上盖后“这个再加厚1毫米”变为5；自主组合L支架的原生特征。支架另验证80×50×45mm外形与双6mm通孔解析体积。首次模型初始化超时，工作区profile隔离后复验通过，不把失败记为成功。

窗口实测在隔离数据目录进行：观察到零件名称、外形尺寸和12项参数；点击“上盖”后界面和CAD快照选择均对应上盖；输入盖厚4并点击准备，显示3→4mm、只涉及上盖；暂停后缩小，辅助功能树和持久状态仍保留草稿、上盖选择、暂停和禁用确认按钮。小窗截图随后返回了被遮挡的其他窗口，未继续盲点确认，不计为完成的小窗视觉或确认执行验收。现有用户工作区未覆盖。详细观察见[`ui-observations.json`](../desktop/validation/ui-observations.json)。

仍未完成：任意工程编辑、追加/删除特征、单孔/单面修改、圆角/曲面、装配约束、用户原生编辑的自动合并、附件内容理解、完整桌面焦点/多屏/退出验收，以及实物加工与组装。几何和参数连续性检查不替代制造与配合验证。

## 对结论的限制

以上156项相交检查属于这次独立验收，网页运行时不自动执行。模块没有体积重叠，不代表有支撑、可以插入、工具能操作或配合合适。

测试控制盒的托盘和盖子仍缺实际固定结构，不能宣称可直接组装或投产。尚未完成真实打印、配件采购、安装电路板、装拆测试、工艺验证、强度或散热验证。按[实施路线](roadmap.md)先验证专业 CAD 操作与桌面协作，再继续控制盒实物验收。

## 组件接口与定向修改补测

2026-11-13用独立的“组件交互验证副本”检查组件接口与真实对话，原控制盒项目记录未变。盒身、盖子、内托盘分别得到48、132、2044个三角面的独立STL，文件结构完整；非法组件序号和不存在的修改对象被拒绝。

指定盖子后问“这个零件叫什么”，回复正确且未新增版本；再说“把这个零件加厚1毫米，其他零件别改”，盖子5→6mm，盒身和托盘测量保持一致。接口与对话记录在测试机器的 `E:\dsh\cad-component-ui-validation-20261113\results.json`，未加入公开示例。

这些验证没有操作浏览器中的鼠标。页面悬停、点击、拖动和布局仍待浏览器权限生效后的实测，不能把接口通过写成UI已验收。
