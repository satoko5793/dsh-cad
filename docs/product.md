# 产品目标：操作专业 CAD 的桌面设计助手

更新日期：2026-11-13。本文记录已确认的产品方向；交互规格见[桌面 Harness 与悬浮小窗](desktop-harness.md)，阶段任务见[实施路线](roadmap.md)。

## 定位与用户

构形 CAD 的目标形态是一个以对话 Harness 为核心的桌面应用，主要能力是在 SolidWorks、Fusion 等专业 CAD 软件中理解工程、创建和修改设计，并帮助用户推进加工与组装。

面向有制作想法但不熟悉 CAD 的普通人，也支持用户在 CAD 中手动操作时随时向助手求助。用户可以用简单语言描述需求、指向当前对象、提出修改，随后在实际 CAD 工程中看到结果、检查并继续编辑。

当前主线是 `desktop/` 的 Electron 完整工作台/悬浮小窗及 FreeCAD 1.1.4 自动连接。已有流式对话、工具/技能配置、视口观察、原生多零件建模与同工程连续修改；采用现成实现的66项接口支持放样、旋转、扫掠等造型，范围见[原生接口](native-interfaces.md)。`cad-studio/` 的网页/CadQuery 思路和代码完整保留为独立原型，见[原型说明](prototype.md)。尚无独立安装包，不把建模等同于装配或制造验证。

## 同一个助手的两种形态

| 形态 | 使用场景 | 核心内容 |
|---|---|---|
| 完整工作台 | 讲完整需求、管理工程、比较方案、检查执行过程 | 对话、工程与附件、工具调用、任务状态、变更与验证记录 |
| 悬浮小窗 | 用户正在专业 CAD 中建模，需要随手提问或发出操作指令 | 简短对话、输入、当前工程和选中对象、执行状态、暂停/取消和展开入口 |

两种形态共享同一会话、任务和工程连接。用户缩小或展开时，草稿、附件、修改对象和执行进度必须连续。开发版已实现同窗切换、置顶、尺寸位置记忆和快捷键；手动交互与多屏等完整验收范围见[交互规格](desktop-harness.md)和[验证记录](validation.md)。

## 核心工作流

**用户提出需求 → Harness 读取当前 CAD 工程与选择 → 澄清关键条件 → 调用 CAD 工具执行 → 在 CAD 中检查结果 → 用户接手或继续对话修改 → 制作与装配验证。**

例如用户在 CAD 中选中一个孔，说“这个改成8毫米”，助手应明确操作对象和目标值，再在正确的工程中修改；不能把聊天中较早提到的孔当成当前选中对象。用户手工修改后，助手需要重新读取相关状态。

专业 CAD 中的原生工程是主要交付物，应尽量保留可编辑的草图、特征、参数、零件和装配关系。不同软件及版本能做到什么，需要通过适配器实测后再承诺；仅导出 STEP/STL 不等于完成原生工程编辑。

## 交互与执行原则

- **使用普通语言。** 先说结果与变化，详细参数和工具记录按需展开；不要求用户学习内部工具名称。
- **先理解用途。** 问清现有物品、安装位置、拆卸需求和必要尺寸，一次优先澄清最关键的信息。
- **明确假设。** 非关键尺寸可以提出默认值并告知；配合尺寸、现有孔位、加工方式和连接条件需要确认或标记待定。
- **目标和范围可见。** 展示正在连接的软件、工程及选中对象；执行前校验对象仍有效，保留未要求修改的设计。
- **允许用户接手。** 用户手动操作与助手写入需要协调；发生工程切换、选择变化或对象失效时，暂停受影响操作并重新读取上下文。
- **过程可检查、可恢复。** 展示计划、执行状态、完成与失败的步骤；支持暂停和取消，在验证过的软件能力范围内提供撤销或恢复，不承诺任意任务都能自动回滚。
- **结论有证据。** 几何、需求符合性、装配和制造是不同层面的验证，模型自述不能替代 CAD 检查或实物验收。

## 创作范围与最终交付

既支持外壳、支架、连接件等实用需求，也保留飞机、恐龙、动漫角色等玩具与作品的趣味创作方向。自由曲面和角色造型是否适合首个 CAD 及其工具能力，需要另行验证；目前不承诺任意形象均可自动生成或制造。

长期交付应逐步覆盖需求记录、可编辑原生工程、按零件的加工文件、材料与数量、标准件清单、装配说明，以及实物反馈到修订的记录。实际加工和组装仍是最终目标，不因接入专业 CAD 而自动视为已经验证。

## 近期取舍与成功标准

FreeCAD 1.1.4 已接入桌面 Harness，完整/小窗共用会话，普通连接无需用户执行宏。下一阶段优先交付可让普通人独立使用的 Windows 内测版，按安装包与数据目录、首次使用引导、项目恢复与错误处理、整体界面打磨的顺序推进，详见[交付与使用体验](release-readiness.md)。本轮先记录文档，后续再实施。

成功标准是未接触项目的用户无需开发者远程配置，完成安装、创建、修改、保存，并在第二天继续工作。复杂修改质量、视觉自查、已有工程协作、附件和新 CAD 适配继续保留，但不以新增工具数量代替使用体验与交付验收。SolidWorks 与 Fusion 是后续候选，实际支持状态见[验证记录](validation.md)。

随后用可打印、可组装的控制盒验证从设计到制作的完整过程。记录用户能否识别操作对象、顺利接手、理解失败原因并完成制作；不以生成模型数量代替完成任务的证据。
