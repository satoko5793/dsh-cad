# 实施路线与下一阶段验收

更新日期：2026-11-13。产品方向见[产品目标](product.md)，已有能力的证据见[验证记录](validation.md)。以下阶段按依赖推进，不代表已经实现或承诺交付日期。

## 当前起点与关键缺口

| 环节 | 已有基础 | 仍需补齐 |
|---|---|---|
| 理解需求 | 文本对话、选中版本和最近对话上下文 | 用途与约束记录、关键缺失信息的引导确认 |
| 表达设计 | 参数、中文模块名、静态多实体组合 | 零件职责、连接关系、标准件和配合条件 |
| 修改 | 口语修改、参数预览、保存/取消和版本回看 | 按设计要求自动检查影响范围与连接关系 |
| 制作准备 | STEP、STL、可再生源码导出 | 加工方式、按零件文件、材料数量和配件清单 |
| 验证 | 实体有效性；部分案例的独立孔槽与相交检查 | 面向具体工艺的规则、装配检查、实物打样 |
| 交付与反馈 | 本地聊天与版本记录 | 装配说明、实物反馈定位、修订验收 |

当前多模块控制盒中托盘与盖子尚缺固定结构，是从几何模型走向可组装物品的直接试点。已有模型可用于讨论，但不是可直接投产的设计。

## 试点：可打印并组装的控制盒

使用者用普通话提出“给这块电路板做个盒子”，系统引导获取实际尺寸和使用条件，输出可交给3D打印服务的零件文件、配件清单和装配说明。首轮拟以常见 FDM 打印和标准螺丝连接为起点；具体材料、打印条件和螺丝规格需在设计前确认。

| 必须确定的输入 | 为什么需要 |
|---|---|
| 电路板外形、厚度、安装孔位置与直径 | 决定内部空间、支撑位置和固定方式 |
| 接口、按钮、线缆与高元件的位置及空间 | 决定开口和内部避让 |
| 放置或安装方式、拆盖频率 | 决定安装结构、盖子定位和紧固方式 |
| 打印方式、材料、加工方能力和尺寸限制 | 决定结构、间隙和零件拆分 |
| 用户可购买的配件及可用工具 | 保证方案能买齐、能装配 |

未知信息保留为待确认项，不能让模型把假设当作用户提供的尺寸。

## 阶段一：把需求和零件关系记录下来

交付设计需求记录，区分用户确认值、系统建议值和待定项；为盒身、盖子、电路板及支撑结构建立稳定标识，记录安装孔、接口与连接关系。

完成条件：普通用户能通过引导问答补齐关键输入；重新打开项目后信息仍在；选中旧版本进行修改时，要求与参数能对应到该版本。暂不依赖照片识别完成输入。

## 阶段二：做出能连接的结构

为试点补齐电路板支撑、盖子定位和选定的紧固结构。选取一套连接方式先做可靠，并保存可复用的建模与参数规则。标准件要记录数量、规格、对应连接位置和装配工具。

完成条件：每个独立件用途明确；托盘或电路板有实际支撑；盖子有定位和固定方式；不存在需要实物悬空的设计解释；零件更改后对应孔位与连接关系能重新检查。

## 阶段三：生成制作资料并检查要求

按零件输出文件和版本清单，形成材料、数量、配件及装配步骤。引入针对选定工艺和连接方式的检查：适用的壁厚与孔槽条件、连接孔对齐、预定间隙、实体重叠、装配路径和工具空间。规则的适用条件与来源必须记录，不能套用到所有材料和工艺。

完成条件：需求中的每项关键条件对应检查结果或明确待人工确认项；文件、清单和说明来自同一版本；普通用户能理解哪些已经检查、哪些尚未验证。相交检查通过不等于完成全部装配检查。

## 阶段四：真实打样、装配与反馈修正

制作试点零件并按说明组装，记录实际材料、打印条件、配件和测量结果。遇到装不进去、孔偏、盖子难拆等问题，用普通话反馈，定位到零件与尺寸，保存修订并再次验证。

完成条件：真实加工和组装已发生，有记录可回看；问题与修订能逐项对应；修订后的文件、配件清单和装配说明同步更新。没有实际样件就不能把这一阶段标为完成。

## 最小实物验收清单

- 需求：电路板、孔位、接口、安装位置及拆卸方式有确认记录。
- 文件：每个自制零件都有匹配版本和数量，加工方能接收并制作。
- 配件：标准件规格和数量完整，用户能买齐且与文件一致。
- 组装：电路板装得下、接口可连接、盖子可固定并按预定方式拆开，必要工具可操作。
- 检查：关键尺寸、配合和实际使用中发现的问题有结果与记录，未验证项明确列出。
- 修订：至少跑通一次实物反馈到设计修改、重新交付与复核的过程。

在试点设计前确定适合该用途的尺寸偏差、装拆与使用验收条件；本文不预设通用于所有零件的数值。完成控制盒闭环后，再根据记录选择支架、连接件或其他加工方式扩展。
