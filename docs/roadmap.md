# 实施路线与验收

更新日期：2026-11-13。以下为目标路线，不代表功能已实现或承诺交付日期。产品定位见[产品目标](product.md)，桌面交互见[交互规格](desktop-harness.md)，现有原型证据见[验证记录](validation.md)。

## 当前起点

仓库已有Electron桌面Harness、完整/小窗同会话和FreeCAD常驻宏。已扩展至控制盒、小龙门架、简化飞机与模型组合的L支架，支持多Body原生特征、参数连续修改、事务恢复及保存重开。原型保留，边界见[原生设计指南](native-designs.md)，未验收项见验证记录。

当前开发顺序调整为：**确定首个 CAD → 验证原生操作闭环 → 桌面 Harness 与小窗 → 稳定的人机协作 → 实际加工组装。**

## 阶段零：确定首个 CAD 和验证环境

首个软件已由用户选定为 FreeCAD，本机验证版本为1.1.4，Windows便携环境已补齐。SolidWorks、Fusion 为后续候选。记录工程类型与集成能力；界面操作要有结果检查，不能只凭点击成功认定完成。

完成条件：选定一款软件和具体版本；确认连接方式、可读取与可写入的范围；得到可复现的测试工程和后续能力验收清单。此阶段不默认两款软件具有相同接口或功能。

## 阶段一：打通专业 CAD 的最小闭环

在实际 CAD 中完成一个简单四孔安装板，而非仅在独立引擎生成交换文件。

| 操作 | 验收证据 |
|---|---|
| 连接并读取工程 | 正确的软件实例、活动文档、单位和当前选择；无文档或断连能明确提示 |
| 创建简单零件 | CAD 中出现可检查的草图、实体与相应特征；记录实际保留的可编辑信息 |
| 修改指定特征 | 修改选中的孔或尺寸，检查其他设计是否保留 |
| 保存原生文件 | 文件能在目标 CAD 中重新打开，确认结构和尺寸仍可编辑 |
| 撤销或恢复一次修改 | 在测试环境验证可恢复路径及其边界，不仅检查工具返回值 |

完成条件：上述步骤在选定版本中真实执行，留下输入、操作、测量、原生文件重开和失败记录。其他 CAD 的适配仍标记未验证。

独立宏/脚本已通过命令行24项、GUI26项检查，详见[FreeCAD验证](../research/freecad-native/README.md)。该探针的 GUI 选择是脚本设置后读回，不能把它视为持续会话或手动协作的证明。

后续开发版已增加常驻 GUI 桥接和写入时上下文校验，且通过 DSH 模型提出计划并实际执行8mm孔径修改。自动原生桥接检查覆盖创建、修改、撤销、重做、保存及过期写入拒绝；手动选择同步、文档切换、断连恢复等完整验收仍待继续，不将本阶段整体标为完成。

## 阶段二：桌面 Harness 与悬浮小窗

提供可独立启动的桌面应用，完整形态承载正常的 Harness 对话、工程、附件、工具调用和任务状态；小窗供用户在 CAD 中工作时使用。两种形态共享会话和任务，切换不启动第二次生成或丢失草稿。

完成条件：按[交互规格](desktop-harness.md)验证缩放、移动、置顶、快捷键、输入焦点、上下文显示、执行中切换和收起后恢复。暂停、取消和失败提示在两种形态下含义一致；语音输入另行规划。

当前已实现 Electron 窗口及上述基础控制；真实窗口观察确认完整/小窗布局和草稿连续，任务自动测试验证暂停、单次确认及重启不重放。仍需完成拖动调整、快捷键冲突、多屏、附件连续、执行中切换及退出保留 CAD 的系统交互验收。尚无独立安装包。

v1.1.0 补齐实际流式文字、模型提供的思考和工具活动，新增技能/工具开关与原生 CAD 视口观察，并完成真实多模态请求及界面滚动测试。下一步继续扩展完整软件面板/错误观察、历史截图管理、模型结论的工程校验及更丰富原生编辑。任意MCP/技能脚本、多会话和通用附件理解仍未实现，详见[Agent 能力配置](agent-tools.md)。

飞机实际闭环已验证看图、同工程参数修改与再观察，但不能新增垂尾或改变机身轮廓。后续新增原生编辑工具和技能优先从[已审查的外部来源](../research/agent-skills-tools/README.md)接入/适配，再验证，不继续为每个造型需求堆本地提示。

## 阶段三：可靠的工程上下文与人机协作

把工程、对象、选择与执行记录关联起来。用户切换文档、手动修改特征、撤销或关闭 CAD 后，助手重新读取状态；写入前检查目标与计划依据是否仍一致。对长任务提供安全停顿点和已完成步骤记录，不通过强制关闭 CAD 实现取消。

完成条件：选中孔后说“这个改成8毫米”修改正确；排队后切换文档不会误改新文档；用户手动更改目标后不会执行过期计划；断连、部分失败、取消与恢复都有可解释结果。保存路径和覆盖已有工程必须明确，不能静默覆盖无关文件。

## 阶段四：在专业 CAD 中完成控制盒制作闭环

系统引导普通用户提出“给这块电路板做个盒子”，形成原生零件与连接关系、按零件加工文件、配件清单和装配步骤。首轮拟以 FDM 打印和标准螺丝连接为起点，具体条件需在设计前确认。

| 必须确定的输入 | 为什么需要 |
|---|---|
| 电路板外形、厚度、安装孔位置与直径 | 内部空间、支撑和固定方式 |
| 接口、按钮、线缆与高元件的位置及空间 | 开口与避让 |
| 放置或安装方式、拆盖频率 | 定位和紧固结构 |
| 打印方式、材料、加工方能力及尺寸限制 | 工艺约束、间隙与拆件 |
| 可购买的配件及可用工具 | 能买齐、能组装 |

需求记录区分用户确认值、建议值和待定项。补齐电路板支撑、盖子定位、选定的紧固结构与标准件对应关系；检查规则记录来源和适用工艺。当前原型中悬空的托盘与盖子可作反例，不当成已完成的装配设计。

制作真实样件，记录材料、加工条件、配件、测量和装配问题。将“孔偏了”“盖子扣不上”等反馈定位到工程对象和尺寸，形成修订并再次交付复核。

### 最小实物验收

- 关键需求有确认记录，原生工程和导出文件来自同一版本。
- 每个自制零件有正确文件、材料、数量；标准件规格、数量和连接位置完整。
- 实际安装电路板、连接接口、固定并按预定方式拆卸盖子，工具有操作空间。
- 孔槽、配合、重叠及工艺条件有对应检查或明确待确认项；几何检查不能替代装配验证。
- 实际加工和组装已发生，有证据；至少完成一次实物反馈、修订和复核过程。

尺寸偏差、装拆与使用条件在试点设计前确定，不预设通用于所有工艺的数值。后续再扩展其他 CAD、其他加工方式、复杂装配与趣味作品，分别记录适用能力和验证结果。
