# 变更记录

## 1.2.1 · 2026-11-13

- 桌面 Harness + 专业 CAD 明确为项目主线；原有网页/CadQuery 思路、实现和数据路径保留为独立原型。
- 桌面代码分为 shell、application、agent、domain、cad/freecad、infrastructure，UI 和 Python 执行器保留各自边界。旧入口继续兼容转发，安装组件、profile、技能和私有数据路径保持稳定。
- DSH 传输与独立 Node 选择提取到 shared；桌面生产代码解除对 cad-studio 的依赖，显式使用桌面工作目录。
- 新增开发指南与各层入口，拆分桌面架构和原型说明，清理重复/过时的协作记录。
- 测试命令自动发现普通测试；仓库更新默认不再重建网页示例，显式 `--export-samples` 保留原流程。
- 验证包括普通测试、分层/兼容检查及实际 Electron/DSH 只读工具回归，详见[验证记录](validation.md)。不以这次重构声称新的 CAD 造型或加工能力。

## 1.2.0 · 2026-11-13

- 接入固定 MIT 上游的66项 FreeCAD 原生接口及参考技能，支持复杂造型和局部特征修改，写入仍需确认并进入原生事务。
- 自动安装 FreeCAD 连接组件、单实例复用、支持的桥接原进程升级与同工程连续修改。
- 原生接口、飞机连续建模及连接生命周期的实测证据见[验证记录](validation.md)，来源见[原生接口](native-interfaces.md)。

更早的流式对话、技能配置、视觉观察、桌面/小窗与网页原型演进保留在验证记录、相关文档和 Git 历史中。
