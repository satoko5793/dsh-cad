# Agent 技能、工具与视觉检查

更新：2026-11-13，桌面开发版 v1.2.2。目标是让用户看清 Agent 正在做什么，也让 Agent 能观察真实 CAD 结果。

## 对话过程

文字直接显示模型增量；模型提供的 reasoning 在“思考”中折叠展示，生成中即可展开、收起、选中复制。消息、summary 和正文节点保留，增量追加文本，不反复重建整条回复。生成阶段先显示原始文字，结束后做安全的简单格式化。没有收到思考文本时只显示运行状态，不补写或猜测内部思考。工具卡片显示准备、执行、返回、失败或中断，可展开输入和结果。取消后保留已生成内容，不继续启动操作。

达到输出上限、无正文等结束情况会单独显示提示，不能藏在思考内容后面。最终持久化的 assistant/message 用于补全可能漏掉的临时文字帧；达到上限不代表任务完成，也不自动重试或执行 CAD。

在对话底部自动跟随文字、工具和布局变化；上翻时暂停跟随，点“回到最新消息”或发送消息恢复。窗口被遮挡、缩为小窗后仍使用相同会话，焦点不因流式事件自动转移。

小窗输入框和发送按钮独立于任务区，展开截图或长计划时仍保持可见；任务区可单独滚动查看全部预览和确认按钮。技能设置的关闭和保存按钮也固定在可见位置。

## 配置能力

输入框下方点“技能与工具”。设置保存在本机 `desktop/.data/agent.json`，下一轮生效；当前任务进行时不能保存新配置。

### 思考强度与输出上限

设置中的“模型生成”支持快速/深入/充分思考（low/high/max）和单次输出上限，默认快速思考、32,768 tokens。复杂建模可以尝试65,536；应用允许输入1,024–262,144之间的整数。这是应用配置范围，实际接受值、思考强度和输出长度仍取决于当前模型服务，不能据此保证所有路由都支持262,144。

思考和正文共用输出额度；上限允许模型输出更长，不要求它必须用完。提高额度可能增加等待及用量，不能单靠提高上限解决长时间思考。DeepSeek 官方对[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)和[模型输出能力](https://api-docs.deepseek.com/api/list-models/)有相应说明，本项目账户路由的实测范围另见验证记录。原网页原型仍沿用自身默认生成参数。

| 工具 | 用途 | 修改工程？ |
|---|---|---|
| `freecad_inspect` | 当前文档、选择、组件、原生几何检查 | 否 |
| `freecad_capture` | 实际 CAD 视口与视角来源 | 否；临时观察视角恢复 |
| `freecad_propose` | 建模或参数修改计划 | 仅提案；确认后才写入 |
| `skill_read` | 按需加载启用的 SKILL.md | 否 |
| 原生接口组：66项 | 草图/对象、放样、旋转、扫掠、圆角、布尔、阵列、参数表、导入导出 | 11项读取/视图；55项写入先进入计划 |
| `freecad_native_plan` | 批量准备明确的原生接口步骤，减少复杂建模往返 | 确认后才执行 |

工具关闭后从本轮 Agent 的可用范围移除；技能不授予新的执行权限。精确示例、参数表和原生操作按钮仍属于用户直接操作路径，同样保留确认和指纹检查。

内置技能：`freecad-native`（原生接口与上游参考）、`native-modeling`（参数配方）、`visual-review`（看图与数据联合检查）、`fabrication-review`（工艺讨论及验证缺口）。源文件在 `desktop/skills/<id>/SKILL.md`，可编辑，下轮读取。`skill_read` 的resource参数可按需读取技能references清单中的Markdown/JSON，不执行脚本。修改后重新打开设置刷新列表。

新增技能和工具优先查已有实现。原生66项工具实际复用MIT mcp-freecad的handlers，原生技能包含上游README、按接口拆分的契约与本地适配规则；其他三个技能仍是本地说明。固定版本、许可证、接口差异及已复用代码见[来源记录](../research/agent-skills-tools/README.md)，完整范围见[原生接口](native-interfaces.md)。没有安装整个上游技能库。

点击“导入 SKILL.md”将说明复制到私有 `desktop/.data/skills/<name>/SKILL.md`。文件需包含 frontmatter `name`（1–64位小写字母、数字、连字符）、`description`，最多24000字；同名拒绝覆盖。首版只复制此说明文件，不复制依赖文件、不执行附带脚本，也未实现任意 MCP 服务配置。不要把需要脚本或外部工具的技能标记成现已可执行。

## 让 Agent 看模型

可以说：“请看看当前飞机模型，获取等轴测和俯视图，说明外观问题，先别修改。”

Agent 可加载视觉技能，读取工程并获取 `current/isometric/front/top/right` 视角的真实视口图。工具会记下工程、指纹、时间、相机与可见对象，取图后恢复原相机和动画设置；近似空白图返回错误，不能当作检查通过。界面“CAD 观察”能展开最新截图，工程变化时标明历史参考。

截图仅针对连接的 FreeCAD 三维视口，不读取其他应用，也不是完整软件面板截图。若需要读取草图编辑对话框、特征属性面板或错误弹窗，当前还需扩展对应观察工具。

图片通过当前 DSH 路由发送给配置的模型。工具查询该模型实际声明的 `inputModalities`；支持 image 才提供 image block，否则告知“仅截图成功，不能声称已看图”。本机 `deepseek-account / deepseek-flash` 已完成真实图像输入测试，但不代表所有提供商都支持。

v1.1.1 复用 FreeCAD MCP 的显示中三维视图判断：表格、工程图等标签在前台时拒绝把后台三维图当成当前画面。看图仍会误判；飞机测试中曾把透视观感误称为“不对称”，增加轮廓坐标核对后，真实模型已撤回该结论。设置对话框的关闭/保存入口也已固定，滚动到底仍可使用。

点击输入框下方“观察”只做本机预览，不自动发起模型请求。要让 Agent 检查，请在对话提出需求。用户附加文件仍只提供文件名，与 CAD 工具截图不同。

检查结论须分清视觉观察、几何数据与未验证项目。截图可能有遮挡或看不见内部；单实体有效不代表零件能装配，模型看图也可能误判。当前不自动做碰撞求解、切片、强度或物理测试。修正仍需另提计划并确认。

## 从旧版本升级

退出旧助手，重新打开并核对标题v1.2.0。连接组件自动配置，支持在原CAD窗口升级，不把磁盘上的修复当成旧进程已更新。最早的旧宏连接首次迁移时可能需保存后重开CAD一次；用户不用手动跑宏或Python。详见[自动连接与单窗口使用](cad-connection.md)。

私有桥接 `observations/` 保留 PNG 与相机来源记录；会话 JSON 保留文字和工具记录，不重复保存图像 base64。当前没有截图自动清理或完整图像历史面板，长期使用需与工程一起备份并管理磁盘占用。
