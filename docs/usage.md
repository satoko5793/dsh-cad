# 使用指南

本文仅用于现有网页与 CadQuery 验证原型，当前主要运行环境为 Windows。目标桌面 Harness、悬浮小窗与专业 CAD 接入尚未提供，交互规格见[桌面 Harness](desktop-harness.md)，能力边界见[验证记录](validation.md)。下文的 `npm start` 启动网页原型，不会连接或修改 SolidWorks、Fusion 工程。

## 首次安装

准备 Git、Node.js 24.9或更新版本、Python 3.13，并确保 `node`、`npm` 和 `py -3.13` 在终端可用。在准备保存项目的位置执行：

```powershell
git clone https://github.com/satoko5793/dsh-cad.git
cd dsh-cad
npm run setup
```

安装脚本会安装根目录和应用目录的 Node 依赖，建立 `cad-studio/.venv`，按 `cad-studio/requirements.lock.txt` 安装 Python 依赖。

若 Python 已安装但 `py -3.13` 找不到，可在仓库根目录使用其实际路径创建环境，再继续安装：

```powershell
& 'D:\Python313\python.exe' -m venv cad-studio/.venv
& '.\cad-studio\.venv\Scripts\python.exe' -m pip install -r cad-studio/requirements.lock.txt
```

`D:\Python313\python.exe` 是路径示例，需要替换为实际位置。Node 依赖尚未完成时仍需分别在根目录和 `cad-studio/` 运行 `npm ci`。

## 模型连接

运行 `npm run dsh -- web`，在原版 DSH 界面配置自己的 DeepSeek API，或使用已有 DeepSeek 账号登录。凭据由 DSH 管理，不放在源码、浏览器代码或设计文件中。

| 配置 | 默认值及用途 |
|---|---|
| `DSH_HOME` | 未设置时为当前用户目录下 `.dsh`，选择已有 DSH 配置与登录所在目录 |
| `CAD_LLM_PROVIDER` | 默认 `deepseek-official`；使用已有账号登录时设为 `deepseek-account` |
| `CAD_LLM_MODEL` | 默认 `deepseek-flash`，选择该路由支持的模型 |

账号登录方式可在同一个 PowerShell 窗口中设置后启动：

```powershell
$env:CAD_LLM_PROVIDER = 'deepseek-account'
npm start
```

已有登录在其他 DSH 目录时，需要同时设置 `DSH_HOME`。应用使用专用 `cad-studio` profile，保留原版 web profile。上述变量只选择已有路由，不会自动配置第三方网关或验证密钥。

CAD 引擎就绪不代表模型服务已连接。启动检测不会发起生成请求；实际连接和生成应分别确认。若切换配置，需要重启本应用服务才能让新的进程环境生效。

## 日常启动

在仓库根目录运行 `npm start`，或双击 `start.cmd`，打开 `http://127.0.0.1:3090`。已有工作台运行时会复用该服务。通过终端启动时应保持该终端打开。

| 命令 | 用途 |
|---|---|
| `npm start` | 启动构形 CAD 并打开网页 |
| `npm start -- --no-open` | 启动工作台，不自动打开浏览器 |
| `npm run status` | 检查服务是否运行，不创建项目或请求模型 |
| `npm run harness` | 原版 DSH 界面，默认端口3080，以终端地址为准 |
| `npm run samples:import` | 导入明确选中的4个公开示例，保留已有同ID项目 |

Node 路径未加入 PATH 时，可在启动终端临时加入安装目录，或用包含实际 Node 路径的本地启动脚本。机器专用路径与凭据目录不提交到仓库。

## 生成和修改

1. 新建零件，描述用途、形状和已知尺寸；也可以选择现有示例。
2. 生成后旋转、平移或缩放模型，查看尺寸与版本。默认长度单位是毫米。
3. 用普通话继续修改，例如“孔径改成8毫米，其他不变”。修改以当前选中版本为基础。
4. 直接修改尺寸时先点“预览修改”；确认后保存新版本，或取消恢复。预览30分钟后不可提交，需要重新预览。
5. 满意后下载当前保存版本的 STEP、STL 或建模源码；未保存的尺寸草稿或预览需要先处理。

多模块模型会显示模块名称、尺寸与实体数量。“底座厚一点”可以采用具体默认改变量并告知；存在多个可能目标时应先澄清。模块组合目前是静态几何，连接方式与实际可组装性仍需单独设计和验收。

## 看清组件并指定修改对象

对具有命名组件的模型：

- 指向模型中的零件，零件边缘与表面会高亮，下方显示名称、尺寸，对应组件卡片同步突出。
- 指向组件卡片可以反向高亮模型；点击卡片或模型中的零件可保持选中。键盘可通过组件按钮选择，画布获得焦点时按 Escape 取消。
- 拖动“分离程度”把组件拉开查看，用“合回原位”恢复。分离只改变显示，不修改设计尺寸、真实位置、保存版本或导出文件。
- 选中后可“只看选中”，再次点击显示全部；“修改这个组件”把输入焦点移到对话框，输入区显示本次修改对象。可直接说“把这个零件加厚1毫米”。选中对象会随请求传给模型，并记录在对应用户消息中。
- 取消选中或切换模型/版本会清除修改对象，避免把上一个版本的选择带入下一次修改。

旧的命名组件版本首次查看时会生成独立显示缓存，需要等待本地CAD计算，不请求大模型、不新增设计版本。未记录组件名称的旧模型保持整体展示；组件加载失败时显示提示，不根据包围盒猜测组件归属。

## 查找项目与查看测试结果

刷新页面或让页面重新获得焦点可更新左侧项目列表。可用 `http://127.0.0.1:3090/?project=<项目ID>` 直达已有项目，切换项目会更新地址栏链接。链接只能访问当前运行机器已有的数据，公开仓库不会自动获得本机项目。

在2026-11-13的测试机器上，左侧有“桌面小龙门架”和“小控制盒（盒身+盖子+内托盘）”；聊天和版本保存在对应项目内。其他机器需自行生成，公开导入清单不包含这两个项目。

## 文件与备份

`cad-studio/.data/` 包含项目聊天、参数、建模源码、历史版本、预览及导出文件，备份应覆盖整个目录。迁移时还需按 DSH 的方式处理模型登录配置；备份设计不等于备份登录。

STEP 用于几何交换，STL 用于网格展示和切片；可再生的参数化来源为脚本与参数，不能承诺导入其他 CAD 后恢复原生特征树。当前导出也不包含完整的材料、标准件和装配交付资料，相关建设见[实施路线](roadmap.md)。
